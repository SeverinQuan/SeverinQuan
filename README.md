# Zhao Junquan / SeverinQuan

I build AI-native tools, full-stack systems, and practical automation for cross-border commerce, personal knowledge workflows, and creative software experiments.

## Current Focus

- AI-native development workflows and agent orchestration
- Full-stack web applications with Python, FastAPI, Vue, and TypeScript
- Cross-border e-commerce tooling, research, and operational automation
- Personal workspace automation with OpenClaw, MCP, and local-first assistants
- Product demos, technical writing, and visual systems with a refined human touch

## Working Style

I care about systems that are useful, legible, and maintainable. My projects usually start from a concrete workflow, then grow into tools that reduce friction, preserve context, and make future work easier.

```text
Idea -> Prototype -> Usable Demo -> Reliable Tool -> Documented System
```
